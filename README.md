# 十消乐 H5 网页游戏

## 玩法说明

- 选择任意两个棋盘上的数字，只要它们的和是10的倍数（如10、20、30等），即可消除。
- 消除后，上方数字会下落补空，棋盘逐渐变空。
- 游戏支持倒计时模式（1分钟或2分钟），时间到自动结算分数。
- 每局结束后可输入玩家名字，分数和用时会记录到本地排行榜。
- 排行榜按分数从高到低排序，分数相同则用时更短的排前面。
- 支持多种棋盘大小和数字难度选择，适配手机和PC。

## 部署方式

1. 直接将本项目所有文件上传到 GitHub 仓库。
2. 进入仓库设置，开启 GitHub Pages，选择 `main` 分支和 `/ten` 目录（或根目录）。
3. 稍等片刻，访问生成的 GitHub Pages 链接即可在线游玩。

也可将本项目部署到任意静态服务器（如 Vercel、Netlify、阿里云OSS、腾讯云COS等），只需保证 `index.html` 可被直接访问。

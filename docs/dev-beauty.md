# 十消乐美化与前后端分离开发计划

## 1. 总体目标

- 实现前后端分离架构，前端采用现代美观的UI框架，**优先移动端H5体验**。
- 后端负责排行榜等数据的持久化存储，支持多人在线排行。
- 保持玩法核心不变，优化交互与视觉效果。
- 新增“破十法”玩法，支持用户在“凑十法”与“破十法”间切换。

## 2. 前端开发计划

### 2.1 技术选型（聚焦移动端H5）

- 框架：React（推荐，生态丰富，适合SPA和PWA）/ Vue（轻量灵活，移动端友好）/ Svelte（打包体积小，性能优）
- **禁止使用Next.js、Nuxt.js等全栈SSR框架，仅限纯前端SPA方案**
- UI库：Ant Design Mobile、Vant、Material UI、Element Plus、Tailwind CSS（移动端优先）
- 状态管理：Redux、Pinia、Zustand、Context API等（视框架而定）
- 网络请求：axios / fetch
- 构建工具：Vite（推荐，启动快，适合现代前端）/ Webpack / CRA
- 移动端适配：rem/vw布局、flex弹性盒、媒体查询、FastClick（消除300ms延迟）等
- PWA支持：可选，提升离线体验和桌面图标

### 2.2 主要页面与模块

- 首页/游戏主界面：棋盘、分数、倒计时、操作按钮
- 设置面板：难度、棋盘大小、倒计时、玩法模式（凑十法/破十法）选择
- 排行榜页面：展示全局排行榜，支持分页/搜索
- 玩家名输入弹窗
- 响应式布局，**以移动端为主，PC端适配为可选优化**

### 2.3 美化与交互优化

- 采用现代配色与扁平化设计，动画流畅
- 棋盘、按钮、弹窗等组件风格统一
- 交互细节优化（如点击、消除动画、排行榜高亮等）
- 支持暗色模式
- 玩法模式切换交互友好，提示清晰
- **所有交互、动画、布局优先考虑移动端触控体验**

## 3. 后端开发计划

### 3.1 技术选型

- 语言/框架：**仅限Node.js（Express/Koa/Fastify等）**
- 数据存储：**仅用本地JSON文件（如leaderboard.json），无需数据库**
- 部署：支持本地和云端（如Vercel、Render、Railway、帽子云等）
- **后端启动方式仅允许npm run build等标准Node.js命令，不允许全栈一体化部署**

### 3.2 主要接口

- 获取排行榜：GET /api/leaderboard
- 提交分数：POST /api/leaderboard
- 清空排行榜：DELETE /api/leaderboard（可选）
- 健康检查：GET /api/health
- （可扩展）支持不同玩法模式排行榜分开存储与查询

### 3.3 安全与扩展

- 简单防刷分机制（如基础校验、IP限制等）
- 预留用户登录/注册扩展接口
- **排行榜仅记录前五名，超出自动截断**

## 4. 任务拆解与里程碑

1. 设计API接口文档与数据结构（含玩法模式字段）
2. 完成后端基础接口与持久化存储
3. 前端项目初始化与UI风格设计（移动端优先）
4. 实现棋盘与核心玩法逻辑（凑十法/破十法可切换）
5. 实现排行榜前后端联动，支持不同玩法模式
6. 优化动画与交互细节（移动端优先）
7. 响应式适配与美化收尾（PC端适配为可选）
8. 部署上线与测试

## 5. 其他建议代码模块化、注释清晰，便于维护

- 前后端接口联调时可用Mock数据
- 适当增加单元测试与端到端测试
- 关注移动端性能与触控体验
- PC端适配可作为后续优化目标

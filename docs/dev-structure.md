# 十消乐 H5 网页游戏

## 1. 项目结构

- `index.html`：主页面，包含游戏界面、设置、排行榜等元素。
- `main.js`：核心逻辑与算法实现，负责棋盘生成、消除判定、分数与排行榜、倒计时等。
- `style.css`：样式文件，负责页面布局与美化。
- `README.md`：项目说明与玩法介绍。

## 2. 游戏玩法与核心逻辑

### 2.1 玩法规则
- 游戏支持两种模式，用户可在设置中选择：
  - **凑十法**：选择任意两个棋盘上的数字，只要它们的和是10的倍数（如10、20、30等），即可消除。
  - **破十法**：选择任意两个棋盘上的数字，只要它们的差（较大数减较小数）是10的倍数（如10、20、30等），即可消除，但两个完全相同的数不能消除。
- 消除后，上方数字会下落补空，棋盘逐渐变空。
- 支持倒计时模式（1分钟或2分钟），时间到自动结算分数。
- 每局结束后可输入玩家名字，分数和用时会记录到本地排行榜。
- 排行榜按分数从高到低排序，分数相同则用时更短的排前。
- 支持多种棋盘大小和数字难度选择，适配手机和PC。

### 2.2 棋盘生成算法
- 棋盘为N×N（如10×10），格子数必须为偶数。
- 随机生成N*N/2对可消除数字（a, b），满足所选模式下的消除条件：
  - **凑十法**：a+b为10的倍数，且a≠b。
  - **破十法**：|a-b|为10的倍数，且a≠b。
- 将所有数字打乱后依次填入棋盘。

### 2.3 消除判定与下落算法
- 玩家每次可选任意两个格子（不要求相邻）。
- 判定方式：
  - **凑十法**：两格数字和为10的倍数，则消除（置为null），并加分（分数=两数之和）。
  - **破十法**：两格数字差为10的倍数且不相等，则消除（置为null），并加分（分数=两数之差的绝对值）。
- 消除后，每一列从下往上收集未被消除的数字，顶部补空（null），实现“下落”效果。

### 2.4 游戏结束判定
- 棋盘上不存在任意一对可消除数字，或倒计时结束，则游戏结束。
- 结束时计算用时，判断是否进入排行榜。

### 2.5 排行榜逻辑
- 排行榜数据存储在localStorage，按分数降序、用时升序排列，最多保留10条。
- 新纪录弹窗输入玩家名，自动更新排行榜。

### 2.6 主要函数说明
- `initBoard()`：生成棋盘初始数字对并填充。
- `renderBoard()`：渲染棋盘界面。
- `handleCellClick(i, j)`：处理格子点击与选中。
- `checkAndRemove()`：判定选中两格是否可消除并执行消除。
- `removeAndDrop()`：消除后处理数字下落。
- `hasRemovablePair()`：判断棋盘上是否还有可消除对。
- `checkGameOver()`：判定并处理游戏结束。
- `updateLeaderboard()`/`renderLeaderboard()`：排行榜数据处理与渲染。

## 3. 交互与设置
- 支持选择数字难度（个位/两位）、棋盘大小、倒计时。
- 支持“凑十法”与“破十法”玩法切换。
- 支持重开、排行榜清空、玩家名输入等交互。
